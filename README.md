# 🤖 AI-Based Student Dropout Prediction System (SIH 2025)

**A high-performance, AI-powered system designed to predict student dropouts and provide actionable counseling insights. Built with React, Flask, and advanced Machine Learning models.**

---

## 🏗️ Project Architecture

This repository contains a full-stack implementation of the Dropout Prediction System:

- **🧠 ML Pipeline**: Random Forest + Logistic Regression ensemble trained on 14k+ students.
- **🔧 Backend API**: Flask-based RESTful API for real-time predictions and analytics.
- **🌐 Frontend Dashboard**: React 19 + Vite dashboard with interactive data visualization.
- **📊 Data Intelligence**: Automatic risk assessment (Low, Medium, High) based on attendance, academic, and financial triggers.

---

## 🚀 Key Features

- **🎯 Real-time Risk Prediction**: Instant ML scoring for student data.
- **📊 Early Warning System**: Identifies high-risk students before they drop out.
- **💡 Actionable Recommendations**: Automated intervention steps for mentors and counselors.
- **📈 Comprehensive Analytics**: Detailed departmental and individual student risk reports.
- **📤 CSV Data Processing**: Upload and process large student datasets with ease.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, Vite, Framer Motion, Lucide React, Lenis Scrolling
- **Backend**: Python, Flask, Pandas, Scikit-learn
- **ML Models**: Random Forest, Logistic Regression
- **Styling**: Modern CSS with HSL variables and HUD-style effects

## 🏁 Getting Started

### Prerequisites

- **Node.js**: v18 or higher
- **Python**: 3.9+
- **npm**: v9+

### Quick Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/happywithu21/AI-Based-Student-Dropout-Prediction-System.git
   ```

2. **Backend Configuration**:
   ```bash
   cd Dropout-System-Working/stack/backend
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   pip install -r requirements.txt
   python app.py
   ```

3. **Frontend Configuration**:
   ```bash
   cd Dropout-System-Working/stack/frontend
   npm install
   npm run dev
   ```
